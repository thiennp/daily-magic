## ONBOARDING-BOOTSTRAP-500 (2026-10-06)

`GET /api/onboarding/bootstrap` returned HTTP 500 with an empty body for fresh accounts because `ensureSampleWorkflowCapability` → `createPublishedCapability` INSERTs `operator_steps`, and production Neon could be missing that column (same class of drift as MARKETPLACE-005 / `workflow_output_fields`). Confirmed live: `POST /api/capabilities/mine` also 500s and leaves `capabilities: []`. Fix: runtime `ADD COLUMN IF NOT EXISTS operator_steps` beside the existing `workflow_output_fields` ensure, migration `070-published-capabilities-operator-steps-repair.sql`, and best-effort seed in the bootstrap route so flags still load if seed fails.

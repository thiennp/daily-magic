# AgentWitch Local Mac app: known issues

| ID          | Symptom                                                                                                                               | Fix                                                                                                                                                                                                                                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MAC_APP-001 | Published DMG is ad-hoc signed and not notarized, so Gatekeeper blocks it on other Macs ("cannot be opened" / "damaged")              | Developer ID + notarize + staple pipeline in `scripts/mac/signing/` (`docs/agent-witch/awl-mac-signing-notarization.md`). Default auto-loads `~/.agentwitch-signing/signing.env`; first real signed run must be on a VM or new macOS user. Without creds it falls back to ad-hoc and logs it; incomplete creds fail loudly. |
| MAC_APP-002 | `security import -P` and `notarytool --password` (Apple ID path) put the secret on argv, visible to `ps` on the build host            | Prefer `NOTARYTOOL_KEYCHAIN_PROFILE` or the ASC API key (no secret on argv for notarytool). Run real signing on a dedicated VM or macOS user.                                                                                                                                                                               |
| MAC_APP-003 | 0.2.2: menu-bar "Open window" / "Settings…" did nothing (app stayed `.accessory`, never activated, so the Window scene never came up) | Fixed in 0.2.3: `MacAppMainWindowPresenter` (Core) switches to `.regular`, activates, focuses or opens the `main` Window and selects the page; back to `.accessory` when the last main window closes.                                                                                                                       |
| MAC_APP-004 | Opened from Downloads / the DMG, macOS runs a translocated (quarantined, read-only) copy                                              | 0.2.3 menu shows "Move AgentWitch Local to Applications". Quit, drag the app into `/Applications`, open it from there.                                                                                                                                                                                                      |

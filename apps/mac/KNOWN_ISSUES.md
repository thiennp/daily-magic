# Agent Witch Local Mac app: known issues

| ID          | Symptom                                                                                                                    | Fix                                                                                                                                                                                                                                                       |
| ----------- | -------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MAC_APP-001 | Published DMG is ad-hoc signed and not notarized, so Gatekeeper blocks it on other Macs ("cannot be opened" / "damaged")   | Developer ID + notarize + staple pipeline in `scripts/mac/signing/` (`docs/agent-witch/awl-mac-signing-notarization.md`). Ready, and runs once `DEVELOPER_ID_APPLICATION` + notary credentials are set. Without them it falls back to ad-hoc and logs it. |
| MAC_APP-002 | `security import -P` and `notarytool --password` (Apple ID path) put the secret on argv, visible to `ps` on the build host | Prefer `NOTARYTOOL_KEYCHAIN_PROFILE` or the ASC API key (no secret on argv for notarytool). Run real signing on a dedicated VM or macOS user.                                                                                                             |

# AgentWitch Local Mac app: known issues

| ID          | Symptom                                                                                                                               | Fix                                                                                                                                                                                                                                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MAC_APP-001 | Published DMG is ad-hoc signed and not notarized, so Gatekeeper blocks it on other Macs ("cannot be opened" / "damaged")              | Developer ID + notarize + staple pipeline in `scripts/mac/signing/` (`docs/agent-witch/awl-mac-signing-notarization.md`). Default auto-loads `~/.agentwitch-signing/signing.env`; first real signed run must be on a VM or new macOS user. Without creds it falls back to ad-hoc and logs it; incomplete creds fail loudly. |
| MAC_APP-002 | `security import -P` and `notarytool --password` (Apple ID path) put the secret on argv, visible to `ps` on the build host            | Prefer `NOTARYTOOL_KEYCHAIN_PROFILE` or the ASC API key (no secret on argv for notarytool). Run real signing on a dedicated VM or macOS user.                                                                                                                                                                               |
| MAC_APP-003 | 0.2.2: menu-bar "Open window" / "Settings…" did nothing (app stayed `.accessory`, never activated, so the Window scene never came up) | Fixed in 0.2.3: `MacAppMainWindowPresenter` (Core) switches to `.regular`, activates, focuses or opens the `main` Window and selects the page; back to `.accessory` when the last main window closes.                                                                                                                       |
| MAC_APP-004 | Opened from Downloads / the DMG, macOS runs a translocated (quarantined, read-only) copy                                              | 0.2.3 menu shows "Move AgentWitch Local to Applications". Quit, drag the app into `/Applications`, open it from there.                                                                                                                                                                                                      |

| MAC_APP-010 | 0.2.5 Start/Stop used the legacy `com.agent-witch` LaunchAgent: Stop was a silent no-op; Start loaded the all-accounts launcher whose SIGTERM then stopped every account host | Fixed in 0.2.6: Start/Stop/Restart use the selected account's `host-services.json` label only; success is judged by that account's `/health`; failures show a real error. The host launcher no longer stops account hosts on SIGTERM and retires the legacy LaunchAgent to a no-op. |
| MAC_APP-011 | 0.2.6 popover Stop label was invisible while running (system `.bordered` style in the MenuBarExtra), no Restart control anywhere (`restartCore()` unwired), and the legacy launcher's no-op line never reached the log | 0.2.7: popover draws its own Restart/Stop labels (plain style, like Show Applications); Restart (`kickstart -k` on the selected account's label) sits next to Stop in the popover and Computer window; bundle 316 logs the retire line before the bootout that SIGTERMs the launcher. `scripts/mac/awlPopoverControls.test.ts` (eb0fcdf9) |
| MAC_APP-012 | 0.2.7 nits: popover footer / window sidebar, status pill and account chip had no VoiceOver labels; the History row always said "History: Offline" while connected; the popover stayed open after Open window / Settings; agent accounts showed the raw "Agt-c7f998a3-…" id as the name | 0.2.8: explicit accessibility labels (shortcut as hint, status pill "Status: …", "Account: …", "Switch account"); History shows "Offline" only when this computer is offline (`resolveHistorySidebarBadge`); Open window / Settings / Sign in close the MenuBarExtra panel; `LocalAccountName` shows "AgentWitch agent" (or the real name) for `agt-…@agents.agentwitch.com`. `AWL028ChromeNitsTests`, `scripts/mac/awl028MacNits.test.ts` (279e425f) |

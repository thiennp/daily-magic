# AWL port discovery and deep links (DF-033)

Since **H6** AgentWitch Local (AWL) listens on a port unique to each account on
the computer (16-port range from 49152, `profiles/<email>/local-port-range.json`),
and saves the port it bound in `profiles/<email>/local-app-port.json`
(`{"localAppPort": n}`). Since **H7** the people-facing surface is the Mac menu
bar app; the browser AWL UI is retired. The legacy `127.0.0.1:43347` is shared
by every macOS user and is only a **last fallback** for pre-H6 cores.

## Choice

| Surface                                                               | Before                                                    | Now                                                                                                                                               | Why                                                                                                                                                                                                                                                                  |
| --------------------------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AWC "Edit on this computer" / Manage pitfalls / Attach PWA            | `http://127.0.0.1:43347/project?id=…` (new tab)           | `agentwitch-local://status?project=<id>[&tab=pitfalls]` (same tab)                                                                                | Works on every H7 Mac build (matcher ignores the query → raises the Computer window); query is forward-compatible for a project route. A `target="_blank"` custom-scheme link leaves an empty tab, so deep links open in place (`resolveProjectEditOnMacLinkProps`). |
| Stuck banner, Writer setup footer                                     | `AGENT_WITCH_LOCAL_APP_ORIGIN` (`/writer-api` is retired) | `agentwitch-local://status`                                                                                                                       | Same — the Mac app is the surface.                                                                                                                                                                                                                                   |
| Bot instructions (agent guide, tasks section, AWL catalog)            | `http://127.0.0.1:43347/prompt-optimizer/agent`           | `http://127.0.0.1:<localAppPort>/prompt-optimizer/agent` + discovery sentence; AWL's own catalog answers with its real `request.socket.localPort` | Bots run on the same computer and can read the port file; a deep link is useless to a bot.                                                                                                                                                                           |
| Human Prompt optimizer page                                           | `http://127.0.0.1:43347/prompt-optimizer`                 | `agentwitch-local://prompt-optimizer[/guide]`                                                                                                     | Only the Mac webview UA gets the HTML (DF-029).                                                                                                                                                                                                                      |
| Health check commands (Repair manually, Repair this computer, Revive) | `curl …43347/health`                                      | `buildAgentWitchLocalHealthCheckCommand(installDir)` — reads `local-app-port.json`, then curls `/health` (bash + zsh)                             | No 43347 fallback: a 43347 answer may be another macOS user's AWL.                                                                                                                                                                                                   |
| Repair script / in-process watchdog / Mac self-heal                   | 43347                                                     | saved port → range → legacy 43347, osUid-checked (DF-030/031)                                                                                     | Old cores still on 43347 keep working.                                                                                                                                                                                                                               |

Shared constants: `packages/shared/src/network/agentWitchLocalAppDiscovery.constant.ts`.
